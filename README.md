Word_trainer.py is designed for training word translation while learning a foreign language. You add the words you want to practice by yourself which makes it wholly personalized. Via editing features you can add, correct and delete pairs of words, building your own flexible dictionary. In practice mode you're offered to type a translation for a randomly chosen word from your dictionary. You have the right to make 3 mistakes after which the correct meaning will be shown. There is no limit in practicing, the words will be popping out until you empty out your whole dictionary, after which you can start over. But you can always type "stop" instead of typing the translation to exit practice mode.
Your dictionary will be contained in the database which will be created at the first launch in the same directory where this file is located. Make sure to keep them both in the same directory otherwise the program will create a completely new empty database at the next launch.
This program has auto keyboard layout switching feature for some cases which is very useful if you have only 2 layouts. But you don't need it if both languages use the same letters (both Latin or both Cyrillic, etc.), so you can choose whether you need it or not at the first launch.
It’s designed for Windows and requires Python 3.6 or higher.
